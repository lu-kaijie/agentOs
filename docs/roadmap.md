# AgentOS Roadmap

## 当前重点

- 稳定 AgentOS 运行时。
- 保持工具 schema 和权限判断行为可预测。
- 优化上下文压缩和大工具结果替换。
- 提升 worktree 和 teammate 流程的可观察性。
- 补充 Hooks、MCP、Memory、Permissions 和多 Agent 相关测试。

## 后续计划

- 增强会话 replay 和 trace 查看能力。
- 增加 Provider 能力检测和更清晰的配置报错。
- 补充更多内置 Skills，例如代码 review、测试修复和代码调整辅助。
- 优化 worktree 清理、合并和冲突处理流程。
- 增加常见本地 Coding Agent 工作流示例。
- 改进长任务执行过程中的进度展示和中断恢复。

## 非目标

- AgentOS 不是托管 SaaS 服务。
- AgentOS 不隐藏工具执行过程。
- AgentOS 不绑定单一模型 Provider。
- AgentOS 不替代人工 code review。
- AgentOS 不默认绕过本地权限和安全确认。
