# 与 Claude Code 的差距

## 当前已经接近的部分

- 常驻交互式 CLI shell
- 代码阅读、搜索、文件修改、测试执行
- session 持久化与持续工作流
- 工具、上下文、role、模型的统一链路

## 当前还没做到的部分

- 更成熟的多 subagent 协作产品体验
- 更强的上下文压缩和更长时程记忆策略
- 更复杂的任务规划与自动恢复
- 更完整的实时观察与事件推送界面
- 更强的安全策略、审批策略和远程执行治理

## 怎么判断它现在的定位

它已经不是 demo，也不是假壳。

更准确的说法是：

- 一个可运行的 Claude Code 类产品原型
- 一个使用 LangChain / LangGraph 构建的 terminal coding agent
- 一个可以继续往产品级演进的基础版本
