# v0.25.0

本里程碑完成了 `interactive-model-backed-agent-shell` 的 `4.x`：

- 主工具运行时切换到 LangChain `StructuredTool`
- `ToolRegistry` 现在持有的是 LangChain-native tools
- 仍保留原有 harness / workspace / fallback 搜索边界
- CLI `tool-list / tool-run / run` 继续兼容

推荐体验用例：

```bash
PYTHONPATH=src .venv-agentos/bin/python -m agentos.cli tool-list
PYTHONPATH=src .venv-agentos/bin/python -m agentos.cli tool-run file_read --arg path=README.md
PYTHONPATH=src .venv-agentos/bin/python -m agentos.cli run \
  "steps: search: agentOs | read: README.md | test: python -c print(456)" \
  --session-id tool-runtime-demo \
  --max-iterations 5
```

你应能观察到：

- `tool-list` 仍列出当前可用工具
- `tool-run` 正常执行，同时底层已经是 LangChain-native tool invoke
- `run` 的工具链路仍保留工作区边界和结构化结果
