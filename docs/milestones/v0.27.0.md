# v0.27.0

本里程碑完成了 `interactive-model-backed-agent-shell` 的 `6.x`，也是这一整条 change 的收尾版本。

最终形态：

- 一个常驻交互式 CLI shell
- 自然语言任务默认走真实模型主路径
- role / context policy / LangChain-native tools / session persistence 已接到同一条连续工作流
- legacy deterministic 路径仍保留，便于验证和回放

推荐体验顺序：

1. 准备模型环境变量

```bash
export OPENAI_API_KEY=...
export OPENAI_BASE_URL=...
```

2. 先跑一次 one-shot

```bash
make run-model
```

3. 再进入常驻 shell

```bash
make shell-model
```

4. 在 shell 内连续输入

```text
请读取 README.md，并告诉我当前项目处于什么阶段
搜索 tests 里和 role handoff 相关的测试
再总结一下当前工具运行时是不是已经切到 LangChain 原生工具了
/status
/exit
```

你应能观察到：

- 不需要每轮重新敲一条独立命令
- 同一个 session 内可以持续推进任务
- session-show 能看到 role_records / role_handoffs / context_policy_records / tool_results
- 真实模型路径会记录 `model_selected=...`

补充体验：

```bash
PYTHONPATH=src .venv-agentos/bin/python -m agentos.cli session-show demo-model-shell
make test
```
