# v0.26.0

本里程碑完成了 `interactive-model-backed-agent-shell` 的 `5.x`：

- 新增真实 `model-backed` runtime 路径
- `run --model` 与 `shell` 的自然语言回合可以走真实模型
- planner / executor / reviewer 三段式 workflow 已接到真实模型与真实工具调用
- 增加模型候选回退，避免默认模型在特定路由下不可用时直接失败

推荐体验用例：

先准备环境变量：

```bash
export OPENAI_API_KEY=...
export OPENAI_BASE_URL=...
```

一条 one-shot：

```bash
PYTHONPATH=src .venv-agentos/bin/python -m agentos.cli run \
  "请读取 README.md，并用两句话总结这个项目当前是什么。" \
  --model \
  --session-id real-model-demo
```

你应能观察到：

- `execution_trace` 中出现 `model_selected=...`
- `role_records` 中 planner / executor / reviewer 都变成真实模型产物
- `tool_results` 中能看到真实工具调用结果

如果默认模型不可用：

- runtime 会自动尝试候选模型
- 最后错误信息会明确列出尝试过哪些模型
