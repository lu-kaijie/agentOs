# v0.22.0

本里程碑完成了 `interactive-model-backed-agent-shell` 的 `1.x`：

- 新增常驻 `agentos shell`
- 支持同一 session 连续多轮输入
- 支持基于 LangGraph 状态流的回合内输出刷新
- 支持 `/status` 查看当前 session 最新状态
- 支持 `KeyboardInterrupt` / `EOF` / `/exit` 退出

推荐体验用例：

```bash
make shell
```

进入 shell 后输入：

```text
say hello
/status
steps: say hello | say again
/exit
```

你应能观察到：

- 不需要反复重新执行 CLI 命令
- 同一个 session 内可以连续工作
- 每轮会看到状态流推进
- `/status` 能看到当前 session 持久化结果
