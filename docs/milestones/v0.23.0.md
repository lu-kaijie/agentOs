# v0.23.0

本里程碑完成了 `interactive-model-backed-agent-shell` 的 `2.x`：

- 新增统一的 `RoleAgent` 协议
- `planner / executor / reviewer` 改为结构化 role 输入输出
- 新增 `role_handoffs` 持久化记录
- session 恢复时会保留 role 相关状态

推荐体验用例：

```bash
PYTHONPATH=src .venv-agentos/bin/python -m agentos.cli run \
  "code: steps: read: README.md | write: notes.txt => role demo | test: python -c print(123)" \
  --session-id role-demo \
  --max-iterations 5
```

然后查看：

```bash
PYTHONPATH=src .venv-agentos/bin/python -m agentos.cli session-show role-demo
```

你应能观察到：

- `role_records` 中出现 `planner / executor / reviewer`
- `role_handoffs` 中记录了从 `planner -> executor` 的切换原因
- reviewer 会对最近工具结果给出结构化复核结论
